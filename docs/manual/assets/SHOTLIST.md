# Screenshot shot list

Use a **fixed window size** (for example **1440×900**), theme **sigil-dark**, and a **non-sensitive sample project** (no real OAuth tokens or API keys on screen).

| Filename | What to capture |
|----------|-----------------|
| `dashboard.png` | Dashboard with service cards visible |
| `layout-overview.png` | Full Studio: sidebar + inspector open + canvas + right panel |
| `stt-inspector.png` | Speech to Text inspector with engine section visible |
| `tts-inspector.png` | Text to Speech inspector |
| `translation-inspector.png` | Translation inspector |
| `transform-inspector.png` | AI Transform inspector |
| `voice-changer-inspector.png` | Voice Changer inspector |
| `canvas-scenes.png` | Canvas and Elements inspector on Scenes |
| `canvas-properties-text.png` | Text element selected, Properties panel open |
| `files-inspector.png` | Files inspector |
| `twitch-inspector.png` | Twitch inspector (logged-out or sanitized) |
| `kick-inspector.png` | Kick inspector |
| `discord-inspector.png` | Discord inspector |
| `obs-inspector.png` | OBS inspector with browser source copy button visible |
| `vrc-inspector.png` | VRChat / OSC inspector |
| `settings-inspector.png` | Settings inspector |
| `project-inspector.png` | Project inspector |
| `control-bar.png` | Bottom status area with STT / AI / TTS controls |
| `client-mirror.png` | `/client` mirror in a browser (optional) |

After exporting PNGs into `docs/manual/assets/`, update each manual page to reference `assets/<name>.png` instead of `ui-placeholder.svg` if desired.

## Naming

Keep **lowercase with hyphens** to match markdown links and avoid cross-platform issues.
