# Sigil user manual

This manual describes **Sigil Studio** (the desktop host) and the **client mirror** used in OBS or other browsers. It is written for streamers and VRChat creators using captions, TTS, chat, and canvas layouts.

## Chapters

- [Overview — getting started, UI, client](00-overview.md)
- [Speech and voice — speech to text and Rewrite, translation, text to speech, voice changer](01-audio.md)
- [Studio — canvas, files](02-studio.md)
- [Integrations — OAuth, Twitch, Kick, Discord, OBS, VRChat](03-integrations.md)
- [System — project, settings, models and runtimes, shortcuts](04-system.md)

## When to update this manual

If you change an inspector flow, default behavior, or a user-visible label, update the matching **section** in the chapter file (or the screenshot list under `assets/SHOTLIST.md`) in the same pull request when practical.
